# PROJECTS PORTFOLIO

# Description
This is a simple website to showcase various projects using React 

# Features

## Add project
- You add the title, the description, and the image URL
## Delete Project
- I just implemented it, maybe to remove a certain project
  
## Search
- Type the project title
## Installation 
- Clone the repo git@github.com:fidelesnjoki-art/Myprojects-portfolio.git
- Cd portfolio
- npm install## Run in the terminal- json-server --watch db.json --port 3001
- npm run dev
## Limitations
-  No edit or update button
-  No authentications
